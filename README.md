# GOMYCODE React-Bootstrap Checkpoint

Simple beginner React app made by Cyrus.

## Run in VS Code

1. Install Node.js if necessary.
2. Open this folder in VS Code.
3. Open Terminal and run:

```bash
npm install
npm start
```

4. Open http://localhost:3000

## What this contains

- One HTML file: `public/index.html`
- `src/index.js`, `src/reportWebVitals.js`, and `src/App.js`
- An `App` component that returns a React fragment (`<> ... </>`)
- A `div` with `className="App"`
- A React-Bootstrap navbar, heading, and three cards

The cards teach HTML, CSS and React. There are no additional components or advanced JavaScript features.

## If starting from scratch using Create React App

```bash
npx create-react-app my-checkpoint
cd my-checkpoint
npm install react-bootstrap bootstrap
```

Follow the instructor's request to remove all files in `src` except `index.js` and `reportWebVitals.js`, then add the provided `App.js`. Replace `index.js` with the provided simple version.

React-Bootstrap documentation: https://react-bootstrap.github.io/docs/getting-started/introduction/
